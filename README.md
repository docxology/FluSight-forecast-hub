# FluSight 2026–2027

This fork retains the CDC FluSight forecast-hub layout for published weekly
influenza hospitalization forecasts and related seasonal targets. The
[documentation index](docs/README.md) explains the layout, the archived
example, and how to verify and render the technical note.

- [Upstream season guide](docs/upstream-season.md) for the challenge scope,
  evaluation data, and attribution.
- [Forecast contribution instructions](model-output/README.md) for the
  existing submission contract.
- [Archived forecast readback](docs/readback.md) for a bounded local check of
  public quantile rows.

The CDC hosts the [upstream hub](https://github.com/cdcepi/FluSight-forecast-hub).
See the upstream guide for attribution and the [archive DOI](https://doi.org/10.5281/zenodo.22101289).
